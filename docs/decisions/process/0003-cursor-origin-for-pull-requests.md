## Decision

Cursor Origin is the codebase and pull-request layer the bots use to inspect repositories, diffs, and checks, and to open pull requests. GitHub is the git host. The coder and the reviewer use Origin for pull requests.

## Rationale

GitHub stores the git history. Origin is how the coder and reviewer inspect the repo and open pull requests.
